# Start Here

## Recommended first session with Codex

1. Create a new private Git repository from this directory.
2. Review `SPECIFICATION.md`, `AGENTS.md`, `ROADMAP.md`.
3. Commit the specification-only starter as the baseline.
4. Open Codex in the repository root.
5. Paste the contents of `prompts/milestones/M0-foundation.md`.
6. Review the result before continuing.
7. Optionally run an independent Codex review using `prompts/review-milestone.md`.
8. Commit/tag M0.
9. Continue with M1 only after M0 is accepted.

## Important campaign-data note

`campaign/import/BG3_Campaign_Tracker.xlsx` is real campaign data supplied as migration input. Keep the repository private or remove that file before publishing the repository.

## Do not skip directly to voice

Voice and screenshot capture are adapters around a reliable state engine. Implement M0–M10 first. A voice agent with an unreliable canonical state would recreate the same long-context problem this project exists to solve.
